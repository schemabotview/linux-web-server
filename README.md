# linux-web-server

**Learn Linux by running your own web server** — a GraphL concept app. Ana's Debian 13 server grows
from a first SSH login to a hardened server serving a static site over HTTPS, with the Red Hat family
(Rocky Linux 10) and macOS shown wherever they differ. 7 courses, 47 sections, ~60 minutes.

Status: plan agreed; see [`COURSE-PLAN.md`](COURSE-PLAN.md). Scenes render with
`@graphlearning/graphl-flow`; the app shell is `@graphlearning/shell`.
